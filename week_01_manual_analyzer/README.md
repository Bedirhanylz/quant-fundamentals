# Week 01 - Manual Stock Analyzer

This project is a pure Python stock analysis tool built without external libraries.

The goal of this project is to understand the core logic behind basic quantitative trading calculations before moving into NumPy, Pandas, and backtesting frameworks.

## Features

* Daily return calculation
* Simple moving average calculation
* Basic moving average signal generation
* Manual implementation using Python lists, loops, conditionals, and functions

## Purpose

Before using financial libraries, I wanted to build the basic calculations manually.
This helps me understand what tools like Pandas, NumPy, and backtesting libraries automate later.

## Concepts Practiced

* Python functions
* Lists
* Loops
* Conditional logic
* Return values
* Basic trading signal logic

## Files

* `manual_analyzer.py`: Main script for the manual stock analyzer
